# Configurar a indexação - Ambientes novo

## Application Overview

Twygo - Gestão de Créditos de IA (Fase 2). Módulo: Créditos de IA → aba Configurações → tabela de ambientes. Esta suite valida o comportamento do toggle "Indexação de conteúdo" para ambientes criados após a implementação do projeto, cobrindo: (1) estado padrão desabilitado do toggle em ambiente novo/independente, (2) bloqueio de edição para ambiente herdado com tooltip de herança, e (3) acesso e estado editável de ambiente independente. Pré-condições: SuperAdmin + contrato com Agente de atendimento habilitado + feature flag analise_creditos_ia_beta_test habilitada. Org ID: 36602. Ambiente herdado de referência: Avião (ID: 36796, Herdar=true). Ambiente independente de referência: _Ambiente (ID: 36799, Herdar=false). Criação de novo ambiente via UI admin NÃO está disponível — REVIEW_NEEDED.

## Test Scenarios

### 1. Configurar a utilização do indexação de conteúdo por ambiente

**Seed:** `tests/seed.spec.ts`

#### 1.1. Configurar a indexação - Ambientes novo

**File:** `tests/features/configurar-indexacao-conteudo-por-ambiente/configurar-a-indexacao-ambientes-novo.spec.ts`

**Steps:**
  1. Acessar https://stage10.stage.twygoead.com/users/login e preencher email=evertongambeta@gmail.com e password=123456 no formulário de login. Clicar no botão 'Entrar'.
    - expect: A URL deve mudar para /dashboard_students e o usuário deve estar autenticado como Éverton Gambeta.
  2. Clicar no botão de perfil (avatar) no canto superior direito e selecionar 'Administrador' no menu de troca de perfil.
    - expect: A URL deve mudar para /o/36602/events?tab=events&profile=admin, confirmando que o perfil Administrador está ativo.
  3. Navegar para https://stage10.stage.twygoead.com/o/36602/ai_consumption_analysis e clicar na aba 'Configurações' (role=tab, name='Configurações').
    - expect: A aba Configurações deve ser exibida como ativa (aria-selected=true) e a URL deve incluir ?tab=settings. A tabela de ambientes deve ser visível com colunas: Ambiente, Acesso de IA ativo, Herdar configurações do principal, Ações.
  4. STEP 1 — Verificar toggle Indexação de conteúdo DESABILITADO por padrão em ambiente novo/independente. REVIEW_NEEDED: Não há botão 'Novo ambiente' acessível via Admin UI. Como alternativa de asserção: Localizar a linha '_Ambiente' (data-item-id='36799') na tabela e clicar no ícone de edição (data-test-id='ai-consumption-analysis-edit-button') para navegar até /o/36602/ai_consumption_analysis/36799/edit_additional_organization_permissions.
    - expect: A URL deve mudar para /o/36602/ai_consumption_analysis/36799/edit_additional_organization_permissions. A página deve exibir o heading H2 '_Ambiente'. O toggle 'Indexação de conteúdo' (input id='ai-consumption-settings-content-indexing-can-ingest', label='Indexação de conteúdo') deve estar DESABILITADO (checked=false) por padrão — confirmando que novos ambientes/ambientes independentes partem com a indexação desligada. REVIEW_NEEDED: Validação com ambiente criado após a implementação do projeto requer setup adicional fora do Admin UI (criação via backend/SuperAdmin). A asserção acima usa proxy environment '_Ambiente' já existente com estado equivalente.
  5. Voltar para a aba Configurações: navegar de volta para https://stage10.stage.twygoead.com/o/36602/ai_consumption_analysis?tab=settings. STEP 2 — Verificar ambiente herdado: Localizar a linha 'Avião' (data-item-id='36796') na tabela. Verificar que o switch na coluna 'Herdar configurações do principal' está MARCADO (chakra-switch__input checked=true). Posicionar o cursor (hover) sobre o ícone de edição (data-test-id='ai-consumption-analysis-edit-button') da linha 'Avião'.
    - expect: O switch de herança na linha 'Avião' deve estar marcado (checked=true). Ao pairar o cursor sobre o ícone de edição, o tooltip com role='tooltip' deve exibir o texto: 'Este ambiente está herdando configurações do ambiente principal. Desative a herança para editar.' Clicar no ícone de edição NÃO deve navegar para nenhuma outra URL (a URL permanece em ?tab=settings), confirmando que o botão de edição está funcionalmente bloqueado para ambientes herdados. REVIEW_NEEDED: Verificar que os recursos de IA do ambiente Avião estão usando os conteúdos corretamente (validação de comportamento do chat/agente no ambiente herdado) está fora do escopo do Admin UI — requer teste funcional na interface do aluno no ambiente Avião.
  6. STEP 3 — Verificar ambiente independente: Permanecer na aba Configurações (ou navegar de volta para https://stage10.stage.twygoead.com/o/36602/ai_consumption_analysis?tab=settings). Localizar a linha '_Ambiente' (data-item-id='36799') na tabela. Verificar que o switch na coluna 'Herdar configurações do principal' está DESMARCADO (chakra-switch__input checked=false). Clicar no ícone de edição (data-test-id='ai-consumption-analysis-edit-button') da linha '_Ambiente'.
    - expect: O switch de herança na linha '_Ambiente' deve estar desmarcado (checked=false), confirmando que é um ambiente independente. O clique no ícone de edição deve navegar para /o/36602/ai_consumption_analysis/36799/edit_additional_organization_permissions. A página de edição deve exibir o heading H2 '_Ambiente' e o formulário de configurações de IA completamente editável (botões 'Salvar' com data-test-id='ai-consumption-settings-edit-save-button' e 'Cancelar' com data-test-id='ai-consumption-settings-edit-cancel-button' devem estar visíveis e habilitados). O toggle 'Indexação de conteúdo' (data-test-id='ai-consumption-settings-content-indexing-master-switch') deve estar presente e interagível, confirmando que o ambiente independente possui configurações próprias não herdadas do principal. REVIEW_NEEDED: Verificar que os recursos de IA do ambiente _Ambiente NÃO herdam as configurações do ambiente principal e estão usando os conteúdos corretamente — requer teste funcional na interface do aluno, fora do escopo do Admin UI.
